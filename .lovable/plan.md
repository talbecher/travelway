## סיווג אוטומטי לפי סוג — פר-מקום

היום הייבוא מכריח קטגוריה אחת לכל המקומות. אשנה כך שכל מקום ייכנס לפי ה-`suggested_type` שכבר מזוהה מה-KML (צבע/אייקון של My Maps + מילות מפתח בשם/תיאור).

### שינויים ב-`src/components/ImportFromMyMapsSheet.tsx`

- **הסרת שלב 3 (מיפוי קטגוריה):** ה-BottomSheet יהיה 2 שלבים בלבד — URL → תצוגה מקדימה.
- **שדה עיר:** יעבור לשלב התצוגה המקדימה (Input אחד מעל הרשימה, אופציונלי).
- **תצוגה מקדימה משופרת:** ליד כל שם מקום יופיע pill קטן עם האייקון של הסוג שזוהה (🍜 / ⛩ / 🏨) — לקריאה בלבד, לא לחיץ.
- **כפתור הייבוא:** במקום לשלוח `type` יחיד, כל שורה תישמר עם `type: p.suggested_type` שלה.
- **State cleanup:** להסיר את `step === "map"`, את הטיפוס `Step`, את `type`/`setType`, ואת ה-`counts` שחישבו סוג רוב.

### שיפור הסיווג ב-`src/lib/maps-import.functions.ts`

הפונקציה `guessType` הקיימת מזהה סוג לפי:
- `styleUrl` / `IconStyle.Icon.href` (צבע/סמל של My Maps)
- מילות מפתח בשם ובתיאור

אשמור את הלוגיקה הקיימת (היא כבר עונה על הדרישה — צבע/אייקון), ורק ארחיב מעט את מילון המחרוזות כדי לצמצם שגיאות:
- hotel: מוסיף `guesthouse`, `motel`, `resort`, `1002` (icon id צהוב של lodging ב-My Maps).
- food: מוסיף `1577`/`1578` (icon ids של restaurant), `izakaya`, `sushi`, `ramen`, `bakery`, `bistro`, `pub`.
- ברירת מחדל נשארת attraction.

אין שינוי בחוזה הטיפוס `ImportedPlace` ואין שינוי בסכמת ה-DB.

### התנהגות סופית

- המשתמש מדביק URL → רואה רשימה עם pill סוג ליד כל שורה → בוחר מה לייבא + עיר אופציונלית → לוחץ "ייבא N מקומות" → כל מקום נשמר עם ה-`type` שלו.
- אין עוד שאלת קטגוריה, אין עוד עריכה ידנית פר-שורה.
