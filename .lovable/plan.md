# Phase 1 — עיצוב מחדש ויזואלי של מסך יום במסלול

**עיצוב בלבד. אפס שינויי לוגיקה.** כל הקריאות לדאטה, ה-DnD, המפה, ה-URL builders, הטפסים וה-sheet-ים נשארים בדיוק כפי שהם. לא מתקינים חבילות חדשות. TypeScript חייב לעבור.

הקובץ היחיד שנוגעים בו: `src/routes/itinerary.$dayId.tsx`.

## מה המשתמש יראה

### 1. כותרת Hero כהה עם תמונה (גובה 110px)

- אם יש פריט ראשון עם `photo_url` — התמונה כרקע מטושטשת (`cover/center`) + שכבת `rgba(0,0,0,0.55)`.
- אחרת — הגרדיאנט של היעד מ-`getDestinationTheme(trip.destination_country)` (כמו היום).
- שורה עליונה (RTL): משמאל כפתורי pill קטנים `[🗺 מפה] [⋯]` — רקע `rgba(255,255,255,0.18)`, לבן, גובה 28px, `rounded-full`, טקסט 11px. מימין — כפתור החזרה הקיים.
- אזור תחתון (`absolute bottom: 10px`): מימין "יום {n}" (22px, לבן, font-500) + תאריך "יום שישי, 10.08" (11px, white/70). משמאל — pill של העיר עם עיפרון + מזג אוויר "☀️ 29° / 18°" אם קיים.
- שורת "ביקרתם ב-{n} מתוך {total}" נשארת (10px, white/60).
- עריכת העיר (editingCity) נשארת בדיוק כפי שהיא.

### 2. כרטיסי פריטים עשירים יותר

- מיכל: `var(--card)`, מסגרת 0.5px, רדיוס 12px, `overflow: hidden`, בלי padding על המיכל (padding פנימי).
- **וריאנט A (יש photo_url):** תמונה ברוחב מלא בגובה 80px (`object-cover`) בראש הכרטיס, ומתחת כותרת (14px, 500), `📍 location` (11px), משך זמן וקטע הערות.
- **וריאנט B (בלי תמונה):** כמו היום — אייקון/אימוג'י 48×48 לצד כותרת + מיקום, עם padding נקי יותר.
- **משך זמן (חדש, ויזואלי בלבד):** אם לפריט ולפריט הבא יש `time_of_day`, מחושב ההפרק עם helper מקומי טהור `parseTime(t)` (split לשעות/דקות → דקות) ומוצג "⏱ 2h 30m" / "45 דקות" בטקסט 10px muted מתחת למיקום. מחושב מהנתונים הקיימים — אין שינוי בלוגיקה.
- **קטע הערות:** 60 תווים ראשונים + "...", 10px, muted, נטוי.
- כל הכרטיס נשאר לחיץ לאותו handler; מסירים את קישור הטקסט "לפרטים ›" ומוסיפים chevron עדין "›" בפינה.
- מחוון הביקור (נקודה ירוקה + ★) נשאר כפי שהוא.

### 3. פס טיימליין

- תווית שעה: רוחב קבוע 44px, יישור לימין, 11px; `var(--foreground)` כשיש שעה, `var(--muted-foreground)` כשאין.
- נקודה: 10px (צבעים לפי סוג כמו היום) + מסגרת לבנה 1.5px.
- קו מקווקו נשאר, opacity 0.4.

### 4. SegmentConnector קומפקטי

- שורה אחת בין שני כרטיסים, `dir="ltr"` על האלמנט:
  `→ {distance}  [🚶] [🚌] [🗺] [🚄]?`
- מרחק: "→ 2.6 ק״מ" ב-11px muted.
- כפתורי אייקון עגולים 28×28: `bg: var(--surface-2)`, מסגרת 0.5px; המוצע/פעיל — `bg: var(--accent)`, לבן, בלי מסגרת.
- 🚶 = URL הליכה הקיים, 🚌 = transit הקיים, 🗺 = Rome2Rio הקיים, 🚄 = NAVITIME (רק ביפן).
- **כל ה-URLs וה-href נשארים בדיוק כפי שהם — רק הפריסה והגדלים משתנים.**

### 5. פס תחתון נקי

- שורת החיפוש: גובה 40px, רדיוס 20px, `bg: var(--surface)` (surface-2 אם אין surface-1), מסגרת 0.5px, placeholder "חיפוש מהיר בגוגל...", גופן 13px. ה-`PlacesSearch` וה-handler לא משתנים.
- ה-FAB: עיגול 56px, handler קיים.
- מסירים את כפתורי "הערה מהירה" ו-"נווט אל" הגלויים — הם נשארים זמינים רק דרך ה-action sheet של ה-+ (ה-handlers וה-sheets עצמם נשארים, רק מוסתרים מהפס).

### 6. פישוט כפתורי הכותרת

- ב-Hero נשארים גלויים רק `[🗺 מפה]` ו-`[⋯]`.
- לתוך תפריט ה-⋯ הקיים מועברים: "הוסף עיר / אזור" (נשאר גם כ-pill בחלק התחתון), "ייצא ל-AI", "🕘 גרסאות" וכל כפתור כותרת נוסף — ה-handlers לא משתנים.

## פרטים טכניים

- עריכה יחידה של `src/routes/itinerary.$dayId.tsx`: קומפוננטות `SortableEntry`, `SegmentConnector`, בלוק ה-Hero והפס התחתון.
- `parseTime` — פונקציה מקומית טהורה בתוך הקובץ.
- משך הזמן דורש העברת `nextEntryTime` כ-prop ל-`SortableEntry` מה-map הקיים (קריאה בלבד, אין מוטציה).
- התמונה ב-Hero נלקחת מ-`entries.find(e => e.photo_url)` — נתון שכבר נטען, אין שאילתה חדשה.
- סגנון: inline styles + טוקנים (`var(--card)` וכו') כמו שאר הקובץ; בלי מחלקות צבע קשיחות.
- בדיקה: typecheck + Playwright במובייל ודסקטופ — hero עם/בלי תמונה, כרטיסים בשני הווריאנטים, connector בשורה אחת, DnD עדיין עובד מהידית.
