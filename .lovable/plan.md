# יצירת טיול נוסף מבורר הטיולים

## מה ישתנה
- כפתור בורר הטיולים בראש המסך יוצג גם כשיש טיול אחד בלבד (לא יוצג כשאין טיולים או במסך יצירת הטיול, כמו היום).
- בתחתית הבורר תתווסף פעולה „+ טיול חדש”: סוגרת את הבורר ופותחת את מסך יצירת הטיול במצב יצירה (בלי edit).
- הבחירה והמחיקה של טיולים בבורר נשארות כמו שהן.

## מה נבדק בקוד (לפני התוכנית)
- אין הפניה אוטומטית שמחזירה משתמש עם טיול מתוך מסך היצירה: שער הכניסה רק בוחר טיול פעיל ולא מנווט, ומסך היצירה נכנס למצב עריכה רק כשיש edit=true.
- „ביטול” במסך היצירה חוזר לבית בלבד ולא משנה את הטיול הפעיל.
- אחרי יצירה מוצלחת, הקוד הקיים כבר מגדיר את הטיול החדש כפעיל וטוען מחדש את האפליקציה לבית, כך שכל המסכים נטענים מחדש עבור הטיול החדש. לא יידרש שינוי.

## גבולות
- בלי שינוי בטופס היצירה, בזרימת העריכה או במסד הנתונים.
- בלי כפתורי יצירה נוספים בבית או בהגדרות.

## פרטים טכניים
- `src/routes/__root.tsx` — `SwitchTripButton`: `trips.length < 2` → `trips.length < 1`; כותרת הגיליון „הטיולים שלי”.
- `src/components/TripPicker.tsx` — prop אופציונלי `onCreateNew?: () => void`; כשקיים, כפתור מלא ברוחב הרשימה (אייקון Plus, גובה ≥44px, צבעי token) מתחת לרשימה. ב־AuthGate לא מועבר, כדי לא לשנות את מסך הבחירה הראשוני.
- ב־`SwitchTripButton`: `onCreateNew={() => { setOpen(false); router.navigate({ to: "/onboarding" }); }}` — בלי search, ולכן בלי edit.
- אימות: `bunx tsgo --noEmit`, `bun run build`; בדיקת דפדפן אם יש לחשבון הבדיקה טיול.
