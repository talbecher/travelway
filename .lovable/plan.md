# סבב ממוקד: שגיאות Discover ומסך המתנה ביצירת טיול

## Discover — הודעות שגיאה לפי סוג הכשל

היום כל תשובה שגויה מ־Google (429, 403, timeout, שגיאת רשת) הופכת ל„לא הצלחנו לזהות את היעד”. ההודעה מטעה.

מיפוי חדש (בשרת, ההודעה בעברית בלבד, בלי פרטים פנימיים):

| מצב | הודעה למשתמש |
|---|---|
| 429 (מגבלת שימוש) | „שירות גילוי המקומות אינו זמין כרגע בגלל מגבלת שימוש. נסו שוב מאוחר יותר.” |
| 403 (הרשאה/הגדרה) | „שירות גילוי המקומות אינו זמין כרגע. נסו שוב מאוחר יותר.” |
| timeout / שגיאת רשת / 5xx | „לא הצלחנו להתחבר לשירות המקומות. בדקו חיבור ונסו שוב.” |
| 200 בלי יעד גיאוגרפי | „היעד לא זוהה. בדקו את שם העיר והמדינה ונסו שוב.” (ללא שינוי) |
| 200 עם יעד עמום | „היעד עמום. דייקו את שם העיר והמדינה.” (ללא שינוי) |

אותו מיפוי יחול גם כשכל חיפושי תחומי העניין נכשלו (למשל 429 באמצע), במקום „החיפוש נכשל” הכללי. בחירת העיר, `city_label` והדירוג לא משתנים.

## Discover — כמה קריאות Google בכל ניסיון (נבדק בקוד)

- חיפוש אחד = קריאת זיהוי יעד אחת + קריאה אחת לכל תחום עניין (1–3) → **2 עד 4 קריאות SearchText**. בנוסף עד 20 קריאות תמונה (מכסה אחרת, לא SearchText).
- פתיחה חוזרת של הגיליון ושינוי תחומי עניין **לא** מפעילים חיפוש — רק לחיצה על „חפש מקומות”.
- בדיקת הרשאת הפיילוט אינה פונה ל־Google.
- לחיצה כפולה: הכפתור ננעל רק אחרי שהמסך מתעדכן, כך ששתי לחיצות מהירות מאוד יכולות לשלוח שני חיפושים. תיקון: נעילה מיידית ברגע הלחיצה, שמשתחררת בסיום החיפוש.

## יצירת טיול — מסך המתנה

- בזמן שמירת טיול חדש מוצג מסך מלא נעים מעל הטופס: אנימציה עדינה (מטוס/מזוודה עם lucide), כותרת „מכינים את הטיול שלך ל־[יעד]…” לפי היעד שהוזן. בלי אחוזים ובלי הודעות „שלב הושלם”.
- צבעים וגופנים מהעיצוב הקיים; רספונסיבי; עם prefers-reduced-motion האנימציה נעצרת ונשאר תוכן סטטי.
- הצלחה: המסך נשאר עד המעבר לבית (המנגנון הקיים טוען מחדש את הדף).
- כישלון: המסך נסגר, הטופס חוזר עם כל הערכים והודעת השגיאה הקיימת.
- שליחה נוספת חסומה בזמן השמירה (כפתור נעול + המסך מכסה את הטופס).
- רק ביצירה; עריכת טיול קיים ללא שינוי.

## פרטים טכניים

- `src/lib/discover.functions.ts`: `placesFetch` מחזיר `{ ok: true, places } | { ok: false, kind: "quota" | "denied" | "network" }` (429 → quota, 403 → denied, abort/חריגה/5xx/אחר → network). לוג שרת עם status בלבד. `messageFor(kind)` ממפה להודעה. בשלב החיפוש: אם אין תחום שהצליח — ההודעה לפי סוג הכשל הראשון.
- `src/components/discover/DiscoverSheet.tsx`: `searchingRef` בתוך `submit` (בדיקה והפעלה סינכרוניות, שחרור ב־`onSettled`).
- `src/routes/onboarding.tsx`: קומפוננטת Overlay מקומית, מוצגת כאשר `!isEditing && (submit.isPending || submit.isSuccess)`; `onSubmit` חוזר מיד אם `submit.isPending`. טופס ולוגיקת השמירה ללא שינוי.
- ללא שינוי סכמה, מכסות או חיוב ב־Google Cloud.
- בדיקות: `bunx tsgo --noEmit`, `bun run build`.
