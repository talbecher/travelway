# פרופיל מטיילים + שיפור כפתורי ייצוא AI

## מה המשתמש יקבל

1. **סקשן חדש "👤 פרופיל המטיילים"** במסך עריכת הטיול (`/onboarding?edit=true`), מתחת לשדות הקיימים. סקשן מתקפל — סגור כברירת מחדל, נפתח אוטומטית אם כל השדות ריקים:
   - **קצב הטיול** — 3 כפתורי בחירה: 🌿 רגוע / ⚖️ מאוזן (ברירת מחדל) / ⚡ אינטנסיבי
   - **מה אנחנו אוהבים** — פילים רב-בחירה: 🍜 אוכל, ⛩ תרבות, 🌿 טבע, 🛍 קניות, 🎭 חוויות, 🏛 היסטוריה
   - **תקציב אוכל ליום** — 3 כפתורים: ₪ חסכוני / ₪₪ בינוני (ברירת מחדל) / ₪₪₪ פרמיום
   - **הערות למתכנן AI** — textarea של 3 שורות, עד 200 תווים
   - נשמר יחד עם השמירה הקיימת (אותו כפתור, אותה mutation).
2. **הפרופיל מוזרק לפרומפט הייצוא ל-AI** — בלוק "👤 פרופיל המטיילים" (קצב, תחומי עניין, תקציב אוכל, הערות) מופיע בתחילת הפרומפט, לפני סקשן המסלול, גם בייצוא המלא וגם בייצוא היום הבודד.
3. **כפתורי ייצוא חדשים** בחלון הייצוא: "העתק + פתח Claude", "העתק + פתח ChatGPT", "העתק + פתח Gemini", "העתק בלבד". כולם מעתיקים את הפרומפט המלא ללוח ופותחים את הכלי בטאב חדש — בלי קיצוץ של 2000 תווים ב-URL. מתחתיהם שורת הוראה: "הפרומפט הועתק ✓ פתח את הכלי והדבק (Cmd+V / Ctrl+V)".

## פרטים טכניים

- **מיגרציה אחת** על `public.trips`: `travel_pace TEXT DEFAULT 'balanced'` עם CHECK בין `relaxed/balanced/intensive`, `travel_interests TEXT[] DEFAULT '{}'`, `food_budget TEXT DEFAULT 'medium'` עם CHECK בין `budget/medium/splurge`, `travel_notes TEXT`. אין טבלה חדשה, אין שינוי RLS (עמודות על טבלה קיימת עם מדיניות קיימת).
- אחרי המיגרציה הטיפוסים מחודשים אוטומטית; `trip.travel_pace` וכו' זמינים בקוד.
- **`src/routes/onboarding.tsx`**: state חדש ל-4 השדות, אתחול מ-`existingTrip` במצב עריכה, והוספת השדות ל-`update` ב-submit (במצב עריכה בלבד — בטיול חדש נשארות ברירות המחדל, והסקשן מוצג גם שם כדי למלא מראש). סקשן collapsible עם `<details>` או state פתיחה: נפתח אוטומטית כשכל 4 השדות ריקים/ברירת מחדל.
- **`src/lib/export-to-ai.ts`**: מיפויי תוויות (`paceLabel`, `budgetLabel`, `interestsText` — שמות התחומים בעברית ולא המפתחות האנגליות) ובלוק הפרופיל מוזרק אחרי שורות הפתיחה (תקציב/סטטוס) ולפני `🗺 המסלול המלא שבניתי:` ב-`generateAIPrompt`, ובאותו מיקום ב-`generateDayAIPrompt`.
- **`src/components/ExportAISheet.tsx`**: החלפת 3 הכפתורים הקיימים ב-4 החדשים; הסרת לוגיקת `?q=` והקיצוץ; `copyPrompt` נשאר; שורת ההוראה מתחת. הכפתור הראשי "העתק פרומפט" הקיים מתמזג לתוך "העתק בלבד".
- ללא תלויות חדשות. אימות: `bunx tsc --noEmit` + בדיקה ידנית במסך עריכת טיול ובייצוא.
