# ליטוש אחרון לבית הפעיל ולמסך היום

## היקף ושימור

- השינוי יוגבל ל־`src/routes/itinerary.$dayId.tsx`, `src/routes/index.tsx`, `src/components/home/ActiveTripHero.tsx` ו־`src/components/home/ActiveTodayCard.tsx`.
- יישמרו כל הלוגיקה, השאילתות הקיימות, הפעולות, הניווט, הלשוניות, סדר האזורים, בחירת תמונות התחנות, מזג האוויר, ייחוס Google והדגשת הפעילות לפי הזמן.
- לא יתווספו טבלה, שמירה, שירות, תלות או בקשת רשת נפרדת.

## 1. עיר ואזור במסך היום

- להעביר את עריכת `city_label` מהפעולה הקטנה שבתוך הכותרת לשורה קומפקטית וגלויה מיד מתחת למספר היום ולתאריך, לפני לשוניות מסלול/מפה.
- השורה תופיע בשני המצבים ותכלול `MapPin`, הכותרת „עיר ואזור היום”, הערך המלא בשבירה תקינה וכפתור עריכה; ללא ערך היא תציג „הוסיפו עיר או אזור”.
- כל השורה או הפעולה יקבלו שטח מגע של 44px ויפתחו את `editingCity` הקיים.
- מצב העריכה ישתמש באותו `cityValue` ובאותה `saveCity`, עם שמירה, ביטול וטקסט העזר „אפשר לציין גם אזור, למשל: טוקיו · שינג׳וקו”.
- לשמור ללא שינוי את החזרה, „עוד”, מזג האוויר של מסך היום, הלשוניות ושאר פעולות הכותרת.

## 2. הפרדת שלושת ערכי המיקום בבית הפעיל

- להרחיב נקודתית את ה־select הקיים של רשומות היום עם `linked_recommendation_id` ועיר ההמלצה המקושרת; לא ליצור שאילתה חדשה.
- לגזור ב־`index.tsx`:
  - `dayAreaLabel`: קודם `todayDay.city_label`, אחר כך עיר מובנית מהתחנה/המלצה, אחר כך `location_name` קצר ואמין, ולבסוף `null`.
  - `weatherCity`: קודם עיר מובנית מהתחנה הראשונה המתאימה או מהמלצה מקושרת; אחרת החלק הראשון של `city_label` לפני `·`, מקף, `/` או `|`; ואם אין מפריד — כל התווית.
  - `photoLocation`: האזור המלא אם קיים, אחרת עיר מזג האוויר, ואחרת יעד הטיול; מנגנון Google Places הקיים יצרף את יעד הטיול לחיפוש בלי בקשה נוספת.
- להעביר לפתיחה את `dayAreaLabel` לתצוגה, את `weatherCity` למזג האוויר ואת `photoLocation` לחיפוש התמונה, בלי להשתמש במיקום המכשיר.

## 3. פתיחת הטיול הפעיל

- להשאיר את שם הטיול מימין ולמקם את שבב מזג האוויר משמאל למעלה, עם אייקון, טמפרטורה ושם `weatherCity`.
- להמשיך להעדיף תחזית לתאריך היום ובהיעדרה את הנתון הנוכחי הקיים; ללא עיר אמינה או נתון מזג אוויר השבב יוסתר, והקישור לתחזית המלאה יישמר.
- להציג את `dayAreaLabel` המלא בשורת היום והתאריך.
- לשמור את גיליון פרטי התמונה, אך להפוך את המפעיל לאייקון `Info` בלבד בגודל 14–16px, ללא קפסולה/רקע/מסגרת/צל, בתוך אזור לחיצה שקוף 44×44px עם focus ו־`aria-label`.
- למקם את האייקון בפינה התחתונה הרחוקה מהכותרת ומהמזג האוויר ולהציגו רק לתמונת יעד שהגיעה מ־Google Places.

## 4. הידוק „היום שלכם”

- לצמצם מעט את הרווח שאחרי הכותרת, את הרווחים האנכיים בשורות ואת גובה המחבר, תוך שמירת הרצף, המספור, התמונות, האייקונים ותנאי החץ/המפריד.
- להשאיר את שם התחנה מודגש ואת השעה והמיקום קריאים, בלי להקטין את הפעולה הראשית או טקסטים מתחת לגודל קריא.
- לעדכן את שורת ההמשך ל־„ועוד תחנה אחת בהמשך היום” או „ועוד N תחנות בהמשך היום”.
