## שיפורי עמוד המלצות + מפה

### 1. תיקון חפיפה בין תג הסוג ("אוכל/אטרקציה") לתג הסטטוס ("רשימה")
בקובץ `src/routes/recommendations.tsx` בקומפוננטת `PlaceCard`:
- הסרת המיקום `absolute top-2 right-2` של תג הסוג. במקום זה, שני התגים (סוג + סטטוס) ירונדרו יחד ב-flex row אחד מעל שם המקום — תמיד, גם ב-tab "הכל" וגם ב-tabs הספציפיים.
- כפתורי ערוך/מחק שיושבים כרגע ב-`absolute top-2 left-2` יישארו במקום, והכותרת תקבל `pl-10` כדי לא להיחסם.
- התוצאה: אין יותר תגים אחד מעל השני.

### 2. כרטיסים יותר מזמינים
עדכון עיצוב הכרטיס ב-`PlaceCard`:
- אם יש `photo_url` — תמונה גדולה (h-32, מלאת רוחב) בראש הכרטיס עם overlay עדין של הסוג בפינה.
- אם אין תמונה — Fallback עם gradient לפי סוג + emoji גדול במרכז (במקום כרטיס "יבש").
- שם המקום גדול יותר, tag אלגנטי, שורת עיר/כתובת עם אייקון pin, ציון גוגל עם ★ צהוב.
- הכפתורים "ניווט" / "+ הוסף ליום" נשארים בתחתית, קצת יותר גדולים.

```text
┌─────────────────────────────┐
│ [   תמונת מקום   ] 🍜 אוכל  │
│                             │
│ Ichiran Ramen               │
│ 📍 Tokyo · Shibuya          │
│ ★ 4.6 גוגל · 2.3 ק"מ        │
│                             │
│ [🧭 ניווט] [+ הוסף ליום]    │
│ סמן שביקרנו · דילגנו        │
└─────────────────────────────┘
```

### 3. בחירה מרובה + מחיקה מרובה
בעמוד `recommendations.tsx`:
- מצב חדש `selectionMode: boolean` + `selectedIds: Set<string>`.
- כפתור "בחר" קטן בכותרת (ליד מתג רשימה/מפה). לחיצה נכנסת למצב בחירה.
- במצב בחירה: כל `PlaceCard` מקבל checkbox עגול בפינה השמאלית העליונה במקום כפתורי ערוך/מחק, לחיצה על הכרטיס מסמנת/מבטלת (לא פותחת גוגל מפות).
- שורת פעולה תחתונה (sticky, מעל ה-BottomNav): "נבחרו N · בחר הכל · מחק · בטל".
- מחיקה = `supabase.from("recommendations").delete().in("id", [...ids])` עם `confirm` והודעת toast. Invalidate `["recs"]`.
- יציאה ממצב בחירה מנקה את הסט.

### 4. מפה — אייקונים בהירים על בהיר + תוויות טקסט
בקובץ `src/components/RecsMap.tsx`:
- שדרוג `pinIcon`: הרקע של הפין יהיה בצבע מלא של הסוג (לא לבן), אייקון emoji בלבן/כהה מעליו לניגודיות גבוהה. תוספת stroke חיצוני כהה + shadow חזק יותר.
  - `food`: רקע `#FF6B6B` (אדום)
  - `attraction`: רקע `#6C63FF` (סגול)
  - `hotel`: רקע `#FFD93D` (צהוב) — עם emoji כהה
- הוספת תווית טקסט קטנה מתחת לפין עם שם המקום (מה שכבר קיים במידע). התווית תרונדר כחלק מה-`divIcon` HTML: label לבן עם רקע כהה חצי-שקוף, גופן 11px, ב-`whiteSpace: nowrap` וגזירה ל-~14 תווים עם `…`.
- הגדלת `iconSize` והתאמת `iconAnchor` כדי שהפין עצמו יישאר על הקואורדינטה המדויקת והתווית תופיע מתחת.

```text
    ┌───┐
    │🍜│  ← pin עגול, רקע צבעוני מלא
    └─┬─┘
   Ichiran   ← תווית טקסט קריאה
```

### קבצים שיערכו
- `src/routes/recommendations.tsx` — תיקון badges, עיצוב כרטיס חדש, מצב בחירה מרובה + מחיקה.
- `src/components/RecsMap.tsx` — pinIcon עם רקע מלא + label טקסט מתחת.

אין שינויי DB, אין שינויי סכמה. כל המידע הדרוש (photo_url, name, type) כבר קיים.
