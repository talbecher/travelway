# Phase 2 — שדרוג מסך הבית במצב "לפני הטיול"

שינוי תצוגה וארגון בלבד, רק בענף שבו `stats.beforeTrip === true`. מצבי "במהלך" ו"אחרי" נשארים בדיוק כפי שהם.

## קבצים שישתנו

- `src/routes/index.tsx` — סידור מחדש של רשימת ה-sections כאשר `beforeTrip`, והעברת ה-hero למצב קומפקטי לפני הטיול.
- `src/components/home/PreTripHero.tsx` (חדש) — פתיחה קומפקטית: שם, דגל/יעד, תאריכים, "עוד N ימים", מזג אוויר קיים. ללא טבעת התקדמות.
- `src/components/home/PlanNextCard.tsx` (חדש) — אזור "ממשיכים לתכנן" עם פעולה ראשית אחת.
- `src/components/home/PrepStatsRow.tsx` (חדש) — שורת "מצב ההכנות" קומפקטית.
- `src/components/home/BudgetSummary.tsx` (חדש) — סיכום תקציב קומפקטי.
- `src/components/home/ToolsRow.tsx` (חדש) — שורת כלים קומפקטית במקום גריד האריחים הגדול.

כל הרכיבים החדשים הם תצוגה בלבד: מקבלים props ו-callbacks מ-`Home()`. אין בהם שאילתות, מוטציות או חישובים עסקיים. רכיבים משותפים (`ChecklistCard`, `DeadlinesCard`, `NearbyCard`, `ProgressRing`) לא ישונו.

## סדר התוכן החדש (לפני הטיול בלבד)

1. פתיחה קומפקטית (~96px): שם הטיול, דגל/יעד, טווח תאריכים + מספר ימים, פיל "עוד N ימים", צ'יפ מזג אוויר הקיים. ללא טבעת אחוזים.
2. "מה צריך לסגור": `DeadlinesCard` הקיים + `ChecklistCard` הקיים, מוצגים רק כשיש בהם תוכן ולאחר סיום הטעינה.
3. "ממשיכים לתכנן": `nextDay` הקיים — יום, תאריך, עיר, 3 פריטים ראשונים, כפתור ראשי "פתח את היום" + קישור שקט "לכל המסלול". אין `nextDay` → הזמנה קצרה לתכנון עם מעבר ל-`/itinerary`.
4. "מצב ההכנות": שורה קומפקטית עם מקומות שמורים, "ימים עם פעילויות", ריקים — כולם מ-`stats2` הקיים. ללא ציון מוכנות מאוחד.
5. תקציב: תקציב כולל, הוצאות, יתרה, קישור ל-`/budget`; מצב "לא הוגדר תקציב" נשמר.
6. כלים ופעולות: מסלול, המלצות, תקציב, מסמכים, שיחון, הוצאה מהירה — בשורה קומפקטית, עם אותו handler והגנת אופליין.
7. "מה קרוב אליי" (`NearbyCard`) נשאר אחרון, ללא שינוי התנהגות.

## טבלת שימור

| יכולת קיימת היום בבית | מיקום בתצוגה החדשה | מי מבצע אותה |
| --- | --- | --- |
| שם/דגל/תאריכים/ספירה לאחור | פתיחה קומפקטית | `PreTripHero` (props מ-`trip`/`stats`) |
| צ'יפ מזג אוויר + קישור לתחזית | פתיחה קומפקטית | `useDayWeather`/`useCurrentWeather` כפי שהם |
| טבעת התקדמות טיול | מוסתרת לפני הטיול בלבד | `ProgressRing` נשאר במצבים active/past |
| דדליינים + פתיחת פרטים | אזור 2 | `DeadlinesCard` + אותו `navigate` קיים |
| צ'קליסט + סימון משימות | אזור 2 | `ChecklistCard` ללא שינוי |
| תצוגת היום הבא | אזור 3 | נתוני `nextDay`+`entriesByDay` הקיימים |
| פתיחת יום | כפתור ראשי באזור 3 | אותו `navigate("/itinerary/$dayId")` |
| מעבר למסלול המלא | קישור משני באזור 3 | `/itinerary` |
| מקומות / ימים מתוכננים / ריקים | אזור 4 | `stats2` הקיים |
| תקציב, הוצאות, יתרה | אזור 5 | `stats` הקיים + `ils()` |
| הוצאה מהירה | שורת הכלים | `openQuickExpense()` + בדיקת `isOnline` הקיימת |
| מסלול/המלצות/תקציב/שיחון/מסמכים | שורת הכלים | קישורים קיימים |
| "מה קרוב אליי" | אזור אחרון | `NearbyCard` ללא שינוי |
| "היינו כאן" | ללא שינוי — מוצג רק בטיול פעיל | `HayinuKanSheet` |
| Live Now / NowNext / DayPreview | ללא שינוי — מצב פעיל בלבד | קוד קיים |
| אין טיול / טעינה | ללא שינוי | `HomeSkeleton` ומסך "אין טיול פעיל" |

## מה לא משתנה

שאילתות, hooks, מוטציות, חישובי תאריכים/תקציב/דדליינים, ניווט, הכותרת המשותפת, GlobalFab, טוקנים גלובליים, מסכים אחרים.

## אימות

`bun run build`; בדיקת TypeScript רק אם כלי כבר מותקן בפרויקט. בדיקה בדפדפן לאחר התחברות: 390px בהיר/כהה, דסקטופ, פתיחת יום, מעבר לתקציב/מסמכים, RTL וחפיפות, וידוא שמצב "במהלך הטיול" לא השתנה. מצבים שלא יהיו נגישים ידווחו במפורש כלא נבדקו.
