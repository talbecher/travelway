# רענון UI למסך היום — אימוץ עיצוב A2 (ללא שינוי לוגיקה)

## מקורות וסדר עדיפויות
1. הלוגיקה וההתנהגות בקוד הקיים — מקור האמת.
2. צילום המסך של A2 (image-13.png) — כיוון חזותי (רפרנס, לא רוחב קבוע).
3. קובץ ה־HTML מ־pen.dev — מידות, צבעים, ריווחים והיררכיה בלבד.

## קבצים שישתנו (גבולות עריכה מחייבים)
- `src/routes/itinerary.$dayId.tsx` — שינוי class names ומבנה תצוגה בלבד, סביב ה־JSX הקיים. האזורים מאותרים לפי שמות רכיבים/handlers ותפקידם, לא לפי מספרי שורות; מספרי שורות בתוכנית הם להתמצאות בלבד.
- `src/styles.css` — רק אם Tailwind והטוקנים הקיימים אינם מספיקים; token/utility חדש עם שם ייעודי למסך היום (למשל `day-*`), בלי להחליף token גלובלי, עם התנהגות dark mode מתאימה.

אין עריכה של שום קובץ אחר, ואין dependency, ספריית פונטים, Tailwind CDN, SVG מהדמו או HTML סטטי מהרפרנס.

## מה לא יועתק מהרפרנס
- קובץ ה־HTML בשלמותו או כרכיב סטטי; Tailwind CDN; Google Fonts חדש; SVG paths מהדמו.
- תוכן דמו: שמות, שעות, מספר תחנות, פעולות שאינן קיימות.
- פריסת רוחב קבוע 390px; ניווט ופעולות דמו.

## צבעים וטוקנים (מתחומים למסך היום)
- עדיפות לטוקנים הסמנטיים ולמחלקות הקיימות; צבעי A2 נכנסים רק כשנדרש ורק במסך היום.
- רקע חם בהיר סגנון `#FAF8F4`, coral לפעולות ולציר, כרטיסים לבנים, גבולות חמים עדינים, טקסט ראשי כהה ומשני אפור־חם.
- אין שינוי משתנים גלובליים. אם נדרש token/utility חדש ב־`src/styles.css`: שם ייעודי למסך היום, בלי החלפת token קיים, כולל dark mode — רקע כהה חם, כרטיסים מובחנים, גבולות עדינים ו־coral נגיש, בלי צבעים בהירים קשיחים.

הכותרת תאמץ את A2 הנקי — בלי תמונת רקע. התמונות נשמרות במלואן בתוך כרטיסי התחנות (thumbnail + fallback קיימים).

## RTL ורספונסיביות
- תמיכה ב־360px, 390px, מובייל רחב יותר ותצוגת desktop קיימת; אין רוחב קבוע.
- logical properties / מחלקות RTL; הציר נשאר מימין ב־RTL; טקסטים ארוכים נשברים בלי גלישה; שמות, עיר, כתובת ושעות לא נחתכים באופן לא קריא; אין גלילה אופקית.

## גובה אזור התוכן
מנגנון המדידה הקיים (`paneH`/`measure`) נשמר. לא מקבעים ערך חדש ל־`paneH` או ל־`calc(100dvh - …)` מראש; מתאימים ערכים רק אם נדרש בפועל כדי למנוע חיתוך הרשימה, שטח ריק גדול, חפיפה עם הסרגל הדביק או בעיה במעבר מסלול/מפה — תוך העדפת חישוב מבוסס מדידה קיימת.

## סיכונים והתמודדות
- **גרירה:** ה־handle וה־listeners נשארים; `onPointerDown stopPropagation` על כפתורי הכרטיס נשמר.
- **ציר הזמן:** הקו הוא שכבה תצוגתית עם `pointer-events: none`; החיבור בין תחנות נשען על הריווח הקיים בין כרטיסים; אחרי התחנה האחרונה אין קו — לפי הרשימה המרונדרת בלבד.
- **dark mode:** כל צבע A2 חדש מוגדר גם למצב כהה באותו utility/token ייעודי.
- **RTL:** הציר והגשר נבנים עם logical properties.
