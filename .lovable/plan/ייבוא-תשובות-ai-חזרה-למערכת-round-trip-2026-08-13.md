# ייבוא תשובות AI חזרה למערכת (Round-trip)

כן, אפשר. הרעיון: הפרומפט שאנחנו מייצאים יכלול "חוזה" ברור — בסוף התשובה ה-AI חייב להחזיר בלוק JSON יחיד בפורמט מדויק. במסך ייעודי מדביקים את ה-JSON, רואים תצוגה מקדימה של מה עומד להיכנס, ומאשרים.

## מה המשתמש יקבל

1. בפרומפט (מסלול מלא / יום בודד / המלצות) נוסיף סעיף אחרון: "החזר בסוף גם בלוק ```json בפורמט הבא", כולל רשימת הערים/הימים והמזהים האמיתיים מהמסלול, כדי שה-AI ידע לאיזה יום לשייך כל פעילות.
2. כפתור חדש בכל מקום שיש בו "ייצא ל-AI": **"📥 ייבא תשובה מ-AI"**.
3. מסך הדבקה: מדביקים את כל תשובת ה-AI (גם עם טקסט מסביב — נחלץ את בלוק ה-JSON אוטומטית).
4. תצוגת אישור לפני שמירה:
   - טאב **מסלול**: כל פעילות מוצעת מקובצת לפי יום, עם צ'קבוקס, שעה, סוג, וכפתור מחיקה. אפשר לבחור בדיוק מה להוסיף.
   - טאב **המלצות**: כל מקום מוצע עם סוג/עיר/הערה/דדליין הזמנה, עם סימון כפילויות ("כבר קיים ברשימה").
5. אישור → הפריטים נוספים בדיוק כמו הוספה ידנית, כולל השלמת קואורדינטות/תמונה/דירוג מ-Google Places לפי שם + עיר (אותו מנגנון של החיפוש הקיים). מה שלא נמצא — נשמר בכל זאת עם אפשרות לתקן מיקום ידנית.

## פורמט מוסכם (מה ה-AI מחזיר)

```text
{
  "version": 1,
  "itinerary": [
    { "day_number": 3,
      "entries": [
        { "title": "מקדש קיומיזו-דרה",
          "entry_type": "attraction",     // attraction | food | transport | note | flight | hotel_checkin
          "time_of_day": "09:00",
          "location_name": "Kiyomizu-dera, Kyoto",
          "description": "להגיע מוקדם לפני ההמונים",
          "icon_emoji": "⛩" }
      ] }
  ],
  "recommendations": [
    { "name": "Ichiran Ramen Shibuya",
      "type": "food",                     // food | attraction | hotel
      "city": "Tokyo",
      "notes": "ראמן טונקוצו, תור קצר בבוקר",
      "booking_deadline": "2026-10-01",   // אופציונלי
      "booking_time": "10:00",            // אופציונלי
      "booking_url": "https://...",       // אופציונלי
      "booking_note": "כרטיסים נפתחים חודש מראש" }
  ]
}
```

כללים שנכתוב בפרומפט: להשתמש רק בערכי הסוג המותרים, `day_number` חייב להיות אחד מהימים שנשלחו, שעה בפורמט HH:MM, בלי שדות מומצאים, ולהחזיר בלוק JSON אחד בלבד.

## פרטים טכניים

- `src/lib/ai-import.ts` (חדש): חילוץ בלוק JSON מטקסט חופשי, ולידציה עם zod (סינון ערכים לא חוקיים במקום זריקת שגיאה כללית), נרמול שעות ואמוג'י ברירת-מחדל לפי סוג, זיהוי כפילויות מול המלצות/פעילויות קיימות.
- `src/lib/export-to-ai.ts`: הוספת סעיף "פורמט התשובה" לשני הגנרטורים (מלא + יום בודד), כולל טבלת `day_number → תאריך/עיר` כדי שהשיוך יהיה מדויק.
- `src/components/ImportAISheet.tsx` (חדש): הדבקה + תצוגת אישור + כתיבה ל-DB (`day_entries` עם `display_order` בהמשך ליום, `recommendations` עם `trip_id`), והשלמת מידע דרך `searchPlaces` הקיים.
- חיבור הכפתור ב-`src/routes/itinerary.index.tsx`, `src/routes/itinerary.$dayId.tsx` (ייבוא ליום הנוכחי בלבד) ו-`src/routes/recommendations.tsx` (ייבוא המלצות בלבד).
- אין שינוי סכימה — כל השדות כבר קיימים.
